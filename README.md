# Практические работы по Java: Базовый синтаксис, UML, ООП и Наследование

Данный репозиторий содержит решения практических заданий (Части 1–3) по дисциплине, направленной на изучение языка Java. В ходе работы были освоены базовые управляющие конструкции, принципы объектно-ориентированного программирования (ООП), проектирование на основе UML-диаграмм, а также механизмы наследования и реализации интерфейсов.

## 📂 Структура проекта

Код разделен на независимые пакеты (директории), соответствующие трем частям практики:

*   `part1_basics` — Базовый синтаксис, массивы, циклы и строки.
*   `part2_uml_authors` — UML-диаграммы, классы и инкапсуляция.
*   `part3_shapes_movable` — Абстрактные классы, наследование и интерфейсы.


## 🛠 Содержание выполненных работ

### Часть 1. Синтаксис и основные управляющие конструкции языка Java (`part1_basics`)
**Цель:** Освоить базовые конструкции языка, работу с массивами, циклами и методами.

*   **Работа с массивами и циклами:** Реализованы программы для инициализации массива (как в C/C++) и вычисления суммы и среднего арифметического элементов с помощью цикла `for`.
*   **Ввод с клавиатуры:** Программа, которая запрашивает у пользователя элементы массива через `Scanner`, вычисляет их сумму с использованием циклов `do-while` и `while`, а также находит максимальный и минимальный элементы.
*   **Аргументы командной строки:** Вывод аргументов, переданных при запуске программы, через цикл `for`.
*   **Ряды и рекурсия/циклы:** Вывод первых 10 чисел гармонического ряда (с форматированием) и вычисление факториала числа через отдельный метод класса с использованием циклов.

### Часть 2. Использование UML-диаграмм при разработке программ (`part2_uml_authors`)
**Цель:** Научиться читать UML-диаграммы классов и реализовывать инкапсуляцию.

*   **Класс `Author`:** Смоделирована сущность «Автор книги» по предоставленной UML-диаграмме. 
    *   Реализованы строго приватные поля (`name`, `email`, `gender`).
    *   Написан конструктор с тремя параметрами (без конструктора по умолчанию).
    *   Созданы геттеры для всех полей и сеттер *только* для email (так как имя и пол менять нельзя).
    *   Переопределен метод `toString()` для вывода информации в заданном формате.
*   **Класс `TestAuthor`:** Тестовый класс для проверки работы конструктора, геттеров, сеттера и вывода объекта на экран.

### Часть 3. Абстрактные суперклассы и производные классы. Интерфейсы (`part3_shapes_movable`)
**Цель:** Изучить механизмы наследования от абстрактных классов, полиморфизм и реализацию интерфейсов.

*   **Иерархия фигур (`Shape`, `Circle`, `Rectangle`, `Square`):**
    *   Создан абстрактный суперкласс `Shape` с защищенными полями (`color`, `filled`), методами геттерами/сеттерами и абстрактными методами `getArea()` и `getPerimeter()`.
    *   Созданы производные классы `Circle` и `Rectangle`, которые переопределяют методы вычисления площади и периметра.
    *   Создан класс `Square` (наследник `Rectangle`), в котором переопределены сеттеры ширины и длины для поддержания равенства сторон.
    *   В классе `TestShape` продемонстрирован **полиморфизм**: создание объектов через родительскую ссылку (**Upcast**), вызов переопределенных методов и явное приведение типов (**Downcast**) для доступа к специфичным методам подклассов.
*   **Интерфейс `Movable` и его реализации:**
    *   Создан интерфейс `Movable` с методами движения (`moveUp`, `moveDown`, `moveLeft`, `moveRight`).
    *   Реализован класс `MovablePoint` (движущаяся точка).
    *   Реализован класс `MovableCircle` (круг, содержащий движущуюся точку в качестве центра).
    *   Реализован класс `MovableRectangle` (прямоугольник, состоящий из двух точек: левый верхний и правый нижний углы), с дополнительной проверкой на одинаковую скорость обеих точек.
